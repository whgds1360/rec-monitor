# 🎥 Rec Monitor

**Rec Monitor** — это легковесное приложение для Windows, созданное для мониторинга и отображения потребления ресурсов ОС в играх и других приложениях. Оно работает как оверлей, оставаясь поверх других окон, чтобы вы всегда могли видеть производительность вашей системы.

## ✨ Особенности

- **📊 Мониторинг FPS в реальном времени**: Отслеживайте производительность любого активного приложения.
- **🔝 Всегда поверх окон**: Оверлей не мешает работе, но всегда находится на виду.
- **⚡ Легковесность**: Не нагружает систему и не влияет на игровую производительность.
- **🎨 Минималистичный интерфейс**: Простой и понятный дизайн, сфокусированный на главном.
